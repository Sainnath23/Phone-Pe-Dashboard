# PhonePe Pulse Business Intelligence Dashboard

## Project Overview

This project presents an end-to-end Business Intelligence solution built using Tableau and the PhonePe Pulse dataset. The dashboard analyzes digital payment trends, user adoption patterns, and regional performance across India through interactive visualizations and KPI-driven insights.

The objective of this project is to transform raw transaction and user data into meaningful business insights that support strategic decision-making and identify opportunities for growth in digital payments.

---

## Key Metrics Analyzed

* ₹121.41 Trillion+ Total Transaction Value
* 72 Billion+ Total Transactions
* 3.2 Billion+ Registered Users
* 36.13% Year-over-Year User Growth
* 10.77% Quarter-over-Quarter User Growth
* 35+ States and Union Territories Analyzed
* 600+ District-Level Insights
